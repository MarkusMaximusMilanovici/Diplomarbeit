## Projektbeschreibung

Im Rahmen unserer Diplomarbeit haben wir ein System entwickelt, das Personen in Echtzeit erkennt und das Kamerabild auf einer LED-Matrix darstellt.

Das System besteht aus einer 9x4 großen LED-Matrix sowie einem zusätzlichen 4er LED-Matrixstreifen. Gesteuert wird das gesamte System von einem Raspberry Pi, der mit einer Kamera verbunden ist.

## Funktionsweise

- Die Kamera erfasst ein Livebild.
- Der Raspberry Pi verarbeitet das Bild.
- Personen werden im Bild erkannt.
- Das Bild wird in Echtzeit auf der LED-Matrix dargestellt.

Bewegungen werden direkt übernommen, sodass eine Live-Anzeige ohne merkbare Verzögerung entsteht.

## Verwendete Hardware

- Raspberry Pi
- Kamera
- 9x4 LED-Matrix
- 4er LED-Matrixstreifen

## Ziel des Projekts

Ziel war es, Bildverarbeitung mit physischer Hardware zu kombinieren und ein funktionierendes Echtzeit-System zur visuellen Darstellung erkannter Personen zu entwickeln.
